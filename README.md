# 💰 FinAdvisor – Digital Financial Advisory Platform

FinAdvisor is a responsive **Digital Financial Advisory Platform** designed to help users manage their financial information, connect with financial advisors, schedule consultations, and access financial education resources.

The project focuses on creating a clean, user-friendly interface using **HTML, CSS, and JavaScript**.

## 🚀 Features

* 🔐 **Login & Registration**

  * User login form
  * New user registration
  * Client and Financial Advisor user types
  * Password confirmation validation

* 📊 **Financial Dashboard**

  * Monthly income overview
  * Monthly expenses
  * Total savings
  * Investment overview
  * Upcoming appointments

* 👨‍💼 **Financial Advisor Search**

  * Search advisors
  * Filter advisors by specialty
  * Filter by experience
  * Filter by rating
  * View advisor information

* 📅 **Appointment Booking**

  * Select financial advisor
  * Choose appointment date and time
  * Select appointment duration
  * Add optional notes
  * Display newly booked appointments in the dashboard

* 📚 **Financial Education**

  * Budgeting resources
  * Introduction to investing
  * Retirement planning resources

* 📱 **Responsive Design**

  * Responsive layout for different screen sizes
  * Mobile-friendly navigation and sections

## 🛠️ Technologies Used

* **HTML5** – Page structure and content
* **CSS3** – Styling, layouts, responsive design, animations, and UI components
* **JavaScript** – User interactions, form handling, dashboard functionality, advisor search interface, and appointment booking

## ⚙️ How It Works

1. Users can access the FinAdvisor homepage.
2. Users can choose to **Login** or **Register**.
3. During registration, users can select whether they are a **Client** or **Advisor**.
4. After successful login/registration, the dashboard is displayed.
5. Users can view their financial overview and search for financial advisor
